<!--
name: 'System Reminder: Tool result partial page offset guidance'
description: >-
  Instructs the model on reading further with offset when a result only covers
  part of a page, or stating partial reading.
ccVersion: 2.1.318
variables:
  - TOOL_NAME
-->
When a ${TOOL_NAME} result carries a note that it covers only a part of the page, read on with offset only if the result lacks what your task needs, or your task needs the whole page. If you do not read on, say in your reply that you read only a part of the page.
