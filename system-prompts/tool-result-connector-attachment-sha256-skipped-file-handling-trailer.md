 begins sha256: (in either case, after any white space), as a reference to a file on this machine does, and this call skips the tool's file handling, so what is written there would have gone to the connector as it is, a file's path and hash included where it holds them. Write there what the tool itself takes in an attachment's ${FIELD_NAME}, or leave that attachment out.
