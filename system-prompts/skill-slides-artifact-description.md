Create a slides artifact — a live presentation deck that looks and edits like a slide editor, published for the team to step through, rework in place, and comment on — for a meeting, a review, a pitch, or a briefing. Use when the user wants slides or a deck to present, rather than a prose document or a chat reply. Only for CREATING a new artifact; edits to an existing artifact modify its HTML directly.
