Publishing a design system to an artifact is not switched on for this session. Anthropic is switching it on for people in stages. If it was switched on for them recently, this session may not have the change yet: a new session gets it within a moment of starting, and an open one can take several hours. Where telemetry is off (with DISABLE_TELEMETRY or DO_NOT_TRACK, for example), Claude Code does not receive these settings, so it stays off there.
