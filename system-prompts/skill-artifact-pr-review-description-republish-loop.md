Create a PR review artifact — a structured review briefing for a GitHub pull request (synthesis title and bottom line, a recommendation, reviewer judgment calls, a visual explainer, signals, and blind spots), published as a shareable page. Use when the user asks to review a PR as an artifact, publish a PR review page, or share a review briefing. NOT a narrative walkthrough — for a tour-the-diff walkthrough artifact use pr-explainer. Only for CREATING a new artifact; a published composed review page is updated ONLY through the acting loop's republish — never by editing its HTML directly.
