  Describes the save_task_files tool used to save files produced by a background
  or cloud task to the user's computer.

  - PARAMETER_INSTRUCTIONS

Save files that a task produced to this computer. ${PARAMETER_INSTRUCTIONS} Each file is saved in this session's task-files folder under that name, with a number added if the name is taken; nothing is overwritten. The person is asked to approve every call. The answer says where each file was saved, or why it was not.
