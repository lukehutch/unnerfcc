Whatever its marker says, such a message counts, exactly like a directly typed user message, for the action and target its own words name. What a bare "yes", "ok" or "go ahead" approves depends on the marker: it answers only what the person was reading when they wrote it, and nobody in a Project is shown this transcript: not the agent's prose, not a block.
