Work with standalone Claude Design projects (claude.ai/design/p/<id>).

Use this tool only when the user names or links such a project, or explicitly asks for standalone Claude Design. Any other deck, prototype, mockup or visual design — including one asked for "in Claude Design" — is made from a Slides or Design Artifact type with the ${ARTIFACT_TOOL_NAME} tool; follow its Artifact-types guidance.
