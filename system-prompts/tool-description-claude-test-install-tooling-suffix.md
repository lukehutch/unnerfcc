A machine without Google Chrome also needs the terminal command once, for the test browser. Three fields of this tool start an install that the install command in a terminal does not offer: noLock, allowFallback and downloadHost. Set a field only when the person has asked for that kind of install in their own words. A plain yes to your own offer is not asking. Never set a field by your own choice. You may run a normal install yourself, with none of the three fields. Do not install another way.
