: This directory was not read, because its address, as written, is outside the directories of the loaded skills of this server. While a skill from this server is loaded, this tool reads, for this server, only the directories of its loaded skills. For a directory of a loaded skill, copy the address after "at" in that skill's first sentence, character for character, without the full stop. Add "/" and a path only for a subdirectory. If this conversation does not hold that sentence, load that skill here: its first sentence then gives the address. To read a directory of another skill of this server, load that skill first.
