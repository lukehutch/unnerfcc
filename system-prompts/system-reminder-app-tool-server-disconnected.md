The app's own tool server has disconnected, so its tools, including the ones you reply with, are unavailable unless it reconnects. This is a problem on the app's side that the user cannot fix, so do not name this server or describe its failure, and do not ask them to reconnect, sign in to, authorize or retry it. Carry on with the request as far as you can. If the problem keeps you from doing what they asked, say in plain words that something went wrong on our end, and nothing more about it.
