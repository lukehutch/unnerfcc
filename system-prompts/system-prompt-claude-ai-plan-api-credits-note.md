- **A claude.ai plan:** Max, Ultra and Team include monthly API credits, which the user (on Team, an owner) claims on claude.ai: `shared/api-sign-in.md`. You can't see whether they can, so promise none. Free, Pro and Enterprise include none. If the user names their plan, tell them which; never say that Max, Ultra or Team doesn't cover the API. If they name none, don't bring plans up unless a call fails for credits.
