<!--
name: 'System Prompt: User local date system reminder rule (short)'
description: >-
  Instructs treating dates or times in user system reminders that lack UTC
  markers as the user's local date.
ccVersion: 2.1.318
-->
. The user's local date can differ. If a system-reminder in a user's message gives a date or time that is not marked UTC, that is the user's local date: treat it as today's date.
