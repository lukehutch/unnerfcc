description: 'Parameter description for (x, y) coordinates within an app window frame.'
ccVersion: 2.1.270
-->
(x, y) in pixels of the most recent app_screenshot's full-resolution coordinate frame (reported with every scaled app_screenshot; equal to the image's pixels for unscaled ones — the AX summary lines use the same space). (0, 0) is the frame's top-left corner; an app_screenshot of the window is required first. Mutually exclusive with element_index and target.
