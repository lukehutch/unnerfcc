Claude Test could not reach the host that the test browser comes from (network or proxy). Tell the person this. Set downloadHost only when the person has typed the mirror's https address to you. An address from the environment, a file or your own earlier command counts only if the person typed it to you. Do not download another way, and do not install Google Chrome unless the person asks you to.
