<!--
name: 'System Prompt: User local date system reminder rule'
description: >-
  Instructs treating non-UTC dates or times in user message system reminders as
  the user's local current date.
ccVersion: 2.1.318
-->
. The user's local date can differ. If a system-reminder in a user's message, other than an earlier "Today's date is" line (that was the UTC date), gives a date or time that is not marked UTC, that is the user's local date: treat it as today's date.
