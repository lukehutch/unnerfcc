 'list_types' lists the published Artifact types this account can start a new Artifact from — titles, descriptions and links (only `type_query` may accompany it); 'describe_type' shows one type's details — its files, whether it ships instructions, the capabilities it uses (pass the type's link as `type_url`, nothing else).
